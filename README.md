# 🎮 Anime Music Quiz (AMQ) Enhancements Scripts

A collection of Tampermonkey user scripts designed to improve your gaming experience on [Anime Music Quiz (AMQ)](https://animemusicquiz.com/).

---

## 📜 Script List & Status

| Script Name | Description | Status | Install Link |
| :--- | :--- | :---: | :---: |
| **`amqKeytoSkip.user.js`** | Allows you to quickly trigger the "Skip" function using a keyboard shortcut. | 🟢 **Active** | [Install](https://github.com/tomokarin/AMQ-Scripts/raw/main/amqKeytoSkip.user.js) |
| **`amqShowYoutubeLink.user.js`** | Adds a direct YouTube search link right below the official song links in the Song Info panel. | 🟢 **Active** | [Install](https://github.com/tomokarin/AMQ-Scripts/raw/main/amqShowYoutubeLink.user.js) |

## 🔍 Detailed Descriptions

### 🟢 Working Scripts

#### 1. AMQ Key to Skip (`amqKeytoSkip`)
* **Purpose**: Streamline your gameplay by binding the "Skip" action to a keyboard button.
* **How it works**: Instead of manually moving your mouse to click the "Skip" button during gameplay, simply press the designated key to skip instantly.

#### 2. AMQ Show YouTube Link (`amqShowYoutubeLink`)
* **Purpose**: Quickly search for the currently playing anime song on YouTube.
* **How it works**: Automatically generates a clickable YouTube search link based on the song title and artist. It is conveniently placed directly below the original audio/video links in the Song Info box.

---

### 🔴 Outdated Scripts

#### 3. AMQ Answer Time Display (`amqAnswerTimeDisplay`)
* **Purpose**: Changes the precision of the remaining answer time from milliseconds to a cleaner, more readable seconds format.
* **Current Status**: **Out of date.** Due to recent AMQ updates, this script is currently deprecated and does not function correctly.

---

## 🚀 How to Install

1. Install a userscript manager browser extension, such as [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).
2. Click on the **[Install]** links in the table above for the script you wish to use.
3. Your userscript manager will automatically open a tab prompting you to install the script. Click **"Install"** or **"Confirm"**.
4. Refresh your AMQ game page, and the scripts will load automatically!
